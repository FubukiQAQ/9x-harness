The built-in text editor

NeuroBench includes a small text editor for the files the assistant produces - batch files, notes, configuration files - without needing anything beyond Notepad.

Opening it

  • File - Text Editor, or the third toolbar button;
  • double-click any text file in the workspace file tree;
  • Workspace - New Text File in Workspace creates and opens one.

Encoding

The editor reads and writes ANSI (GBK on Chinese systems), like every program of this era, so the files it writes are understood by cmd.exe and Notepad.

UTF-8 files will show garbled Chinese. That is expected: open them in Notepad, choose Save As and pick ANSI.

Writing batch files

Save as ANSI and begin with:

@echo off chcp 936
