Quick start

1. Start the program

Choose Start - Programs - 9xHarness - 9xHarness, or double-click the desktop icon. A splash screen appears for a second or two.

2. Fill in the server details

Open Tools - Options:

FieldMeaning
Server URLFull endpoint, e.g. https://api.deepseek.com/chat/completions
Model nameWhatever your provider calls it, e.g. deepseek-chat
API keyThe key from your provider, usually starting with sk-
Timeout (s)Use 60 on an old machine
Max outputTokens per answer; 1024-2048 is sensible

Press Test connection. "Network, encryption and authentication all OK" means you are ready.

3. Talk to it

Type in the box under the conversation pane, then press Ctrl+Enter or click Send. While it works the status bar shows "Connecting to server..." and the buttons grey out. Press Esc or Stop to abandon the request.

4. Let it do things

Tick Allow the assistant to use local tools at the bottom of the window, then ask for example:

What folders are on drive D? Read notes.txt from my workspace and fix the typos Write a batch file that backs up D:\work to C:\BACKUP.BAT How much memory does this machine have?

Whenever it wants to write a file or run a command, a confirmation box appears and you can say No.

Careful: cloud answers are not always right. Read every command before you approve it, especially anything that deletes files.
