9xHarness

A desktop assistant for old machines.

9xHarness is a desktop assistant for legacy PCs (Windows 95 / 98 / NT 4.0 / 2000 / XP). It sends your question over an encrypted connection to a cloud service and shows the answer in this plain three-pane workbench. It can also read and write files on this computer, run commands and report system information - that is what "tool calling" means here.

Three things that make it unusual

  • Secure connections on old systems. Windows XP only speaks TLS 1.0, which modern servers refuse. NeuroBench carries its own SSL/TLS 1.2 stack (BearSSL), so it does not depend on any operating-system crypto service and works even on Windows 95.
  • It knows it lives on an old machine. The instructions sent to the cloud describe this host: Windows XP, 128-512 MB RAM, code page 936, no PowerShell, no Python, IE6 only. Answers therefore fit the machine instead of suggesting software you cannot install.
  • It can actually get work done. List folders, read and write files, run commands, open documents and put text on the clipboard. Anything risky asks for confirmation first.

Before you start

  1. Open Tools - Options and fill in the server URL, model name and API key, then press Test connection.
  2. Open Tools - Activate Product and enter the product key from your disc sleeve. Without a key the program runs as a 30-day / 30-conversation trial.
Note: this program ships no cloud account of its own. Ask your supplier for the server URL and key.
