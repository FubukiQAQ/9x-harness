Server and key settings

Where settings live

Settings are stored in 9XHARNESS.INI in the program folder. If that folder is read-only the file goes to Application Data\9xHarness\9XHARNESS.INI instead. It is a plain INI file and can be edited in Notepad:

[connection] endpoint=https://api.deepseek.com/chat/completions model=deepseek-chat apikey=(stored lightly obfuscated) temperature=7 maxtokens=2048 timeout=60 [options] usetools=1 confirmwrite=1 ignorecertdate=0 [display] fontsize=12 language=en

Meaning of each value

KeyMeaning
endpointFull URL of an OpenAI-compatible chat/completions endpoint; must start with http:// or https://
modelModel name as required by your provider
apikeyYour key. It is obfuscated, not encrypted - do not share 9XHARNESS.INI
temperatureTemperature x10 (7 = 0.7)
maxtokensAnswer length limit; keep it modest on old machines
usetools1 = the assistant may use local tools
confirmwrite1 = always ask before writing files or running commands
ignorecertdate1 = ignore certificate date errors (only if the clock is wrong)
languagezh or en - the user interface language

About the secure connection

9xHarness verifies server certificates against the root certificates in the CERTS folder. If a server switches to a new certificate authority the program reports "server certificate not trusted"; run CERTUPD.EXE from the tools disc, or drop a new PEM bundle into CERTS.

Wrong clock? A dead CMOS battery is common on these machines and makes certificate dates fail. Fix the system clock first; if you cannot, tick "Ignore certificate date errors" and the program will try to correct the time from the network.

Proxy servers

HTTP proxies are not supported. If your network needs one, ask your administrator to allow direct outbound access to port 443.
