工作区与文件

三个窗格分别是什么

窗格用途
左：工作区搜索 / 工作区列表搜索并选择工作区。每个工作区就是磁盘上的 一个文件夹。
中：文件搜索 / 当前工作区内的文件当前工作区文件夹里的文件。双击文本 文件用内置编辑器打开；双击会话文件（*.NBC）则载入该会话。
右：对话消息 / 输入对话记录与输入框。

工作区是什么

每个工作区是 Application Data\9xHarness\Workspaces\<名称> 下的一个文件夹。您在这个工作区里的对话会按文件夹收纳，文件名形如 CONV-20031118-1432.NBC，与您放在里面的文本文件并列存放。切换工作区会 同时切换对话历史和文件列表。

常用操作

  • 工作区 - 新建工作区：建立文件夹并切换过去。
  • 工作区 - 在工作区中新建文本文件：新建并立即用编辑器打开。
  • 工作区 - 把文件加入工作区：把别处的文件复制进来。
  • 工作区 - 打开工作区文件夹：在资源管理器中打开。
  • F5 或 工作区 - 刷新：重新读取文件夹。
  • 在文件树上按鼠标右键，可以“打开 / 删除 / 刷新”。

会话文件

会话文件是带几行 ; 表头的纯文本，可以直接用记事本或内置编辑器查看。 文件 - 保存会话 会把当前对话写入该文件；在文件树上删除会话文件即从磁盘删除。

建议：一个项目用一个工作区。这样助手为该项目生成的所有东西 都在同一个文件夹里，方便整体复制到软盘或打成压缩包。
