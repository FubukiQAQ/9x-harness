Troubleshooting

1. "Root certificates not found (CERTS folder missing or empty)"

The CERTS folder or its PEM bundle is gone. Reinstall, or run CERTUPD.EXE from the tools disc to import a bundle.

2. "Cannot resolve server address"

Check the cable or modem, confirm you can open any page in a browser, check the URL for stray spaces, and check your DNS settings.

3. "Failed to establish a secure connection"

  • Check the system date and time first - wrong time breaks certificate validation;
  • Make sure the URL starts with https://;
  • "certificate not trusted" means the root bundle is out of date: run CERTUPD.EXE;
  • "no cipher suite in common" means the server only accepts TLS 1.3, which this client cannot do; use a TLS 1.2 endpoint.

4. "The server rejected the request (HTTP 401)"

The key is wrong, expired or out of credit. Check it on your provider's site.

5. Strange boxes or question marks in the transcript

Font problem. Make sure SimSun is installed, and try a larger font size in Tools - Options.

6. The assistant says it cannot browse the web

Correct: it has no browser. It can only use the tools listed in this help file and the text you paste into the input box.

7. Does it run on Windows 98?

Yes. It is a 32-bit program with no .NET or modern runtime dependencies; Windows 95 OSR2 or later with IE4+ is enough. On such machines keep Max output below 512 tokens.

8. Where are conversations stored?

In the current workspace folder, as .NBC text files. They are saved automatically after each answer; File - Save Conversation forces a save.

9. Why is every answer slow?

The CPU does the TLS maths in software and the link is slow. 5-20 seconds per answer is normal; lower Max output to speed it up.

10. How do I remove the program?

Use Start - Programs - 9xHarness - Uninstall 9xHarness or Add/Remove Programs. Your own documents and workspaces are left alone.
