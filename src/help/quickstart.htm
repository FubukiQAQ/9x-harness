快速安装与使用

第一步：启动程序

从「开始 - 程序 - 9xHarness」中单击 9xHarness，或者双击桌面上 的图标。启动时会显示一个启动画面，稍等一两秒即可。

第二步：填写服务器信息

选择菜单「工具 - 设置」，填写：

项目说明
服务器地址完整的接口地址，例如 https://api.deepseek.com/chat/completions
型号名称服务商规定的型号，例如 deepseek-chat
API 密钥服务商给您的密钥，通常以 sk- 开头
超时(秒)老机器建议填 60
最长输出一次回答最多多少令牌，建议 1024~2048

填好后按「测试连接」。提示“网络、加密与鉴权全部正常”就说明可以用了。

第三步：开始对话

在右栏下方的输入框里输入问题，然后按 Ctrl+Enter 或单击「发送」。 等待时状态栏会显示“正在连接服务器...”，按钮暂时变灰。要中途放弃，按 Esc 或单击「停止」。

第四步：让它动手做事

先确认窗口下方的「允许智能助手调用本机工具」已勾选，然后可以这样问：

帮我看看 D:\ 下面有哪些文件夹 把工作区里的 notes.txt 读出来，把错别字改一下再存回去 写一个自动备份 D:\工作 的批处理，存到 C:\BACKUP.BAT 这台电脑内存多大？还能装点什么？

每当助手要写文件或执行命令，都会弹出确认框，您可以选择“否”。

注意：云端回答并不总是正确。涉及删除文件、修改系统设置的 命令，请务必自己看过再同意执行。
