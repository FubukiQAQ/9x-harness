Version history

3.00.2003 (November 2003)

  • First release of the 9xHarness workbench: workspace list, workspace file tree and conversation pane.
  • Tool calling: read/write files, list folders, run commands, system information, clipboard.
  • Built-in SSL/TLS 1.2 stack so Windows 95/98/2000/XP can reach modern servers.
  • Built-in text editor; double-click a file in the tree to edit it.
  • Product key activation and a 30-day trial.
  • Chinese and English user interface, switchable at run time.
  • HTML Help (.CHM) documentation.

3.01.2003 (Service Pack 1)

  • Updated root certificate bundle.
  • Updated help file.
  • New system information reporting tool (SYSINFO.EXE).
  • Minor interface fixes.

1.60.0412 (beta)

  • Wizard-based installer.
  • Fixed clipped dialogs at 800x600.
