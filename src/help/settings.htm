配置服务器与密钥

配置文件在哪里

设置保存在程序目录下的 9XHARNESS.INI 中。如果程序目录不可写，会自动 改存到 Application Data\9xHarness\9XHARNESS.INI。它是老式 INI 文件， 可以用记事本直接修改：

[connection] endpoint=https://api.deepseek.com/chat/completions model=deepseek-chat apikey=（这里是经过简单混淆的密钥） temperature=7 maxtokens=2048 timeout=60 [options] usetools=1 confirmwrite=1 ignorecertdate=0 [display] fontsize=12 language=zh

各项设置的含义

项目含义
endpoint接口的完整网址，必须是 OpenAI 兼容的 chat/completions 接口，以 http:// 或 https:// 开头
model型号名称，由服务商规定
apikey密钥。保存时会做简单混淆（不是加密），请不要把 9XHARNESS.INI 发给别人
temperature温度 x10。7 表示 0.7，数值越大回答越活泼
maxtokens单次回答的令牌上限，老机器不建议超过 2048
usetools1 = 允许助手调用本机工具
confirmwrite1 = 写文件、执行命令前弹出确认框（强烈建议保持 1）
ignorecertdate1 = 忽略证书日期错误，仅当本机时钟不准时使用
languagezh 或 en，界面语言

关于安全连接

本程序自带 SSL/TLS 1.2 组件，证书由 CERTS 文件夹中的根证书校验。 如果服务器换用了新的证书颁发机构，程序会提示“服务器证书不受信任”，此时请运行 工具光盘中的 CERTUPD.EXE，或把新的证书包放进 CERTS 文件夹。

本机时钟不准怎么办？老电脑的 CMOS 电池没电是常事，系统时间 可能停在 2001 年，这会导致证书日期校验失败。请先更正系统时间；实在无法更正时， 可在设置中勾选「忽略证书日期错误」，程序会尝试用网络时间校正。

代理服务器

本程序不支持 HTTP 代理。如果您的网络必须经过代理才能上网，请与网络管理员联系， 为 443 端口开放直连。
