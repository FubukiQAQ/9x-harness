Workspaces and files

The three panes

PanePurpose
Workspace search / Workspaces (left)Search and choose a workspace. Each workspace is a folder on disk.
File search / Files in workspace (middle)The files inside the current workspace folder. Double-click a text file to open it in the built-in editor; double-click a conversation (*.NBC) to load it.
Conversation / Input (right)The transcript and the box you type in.

What a workspace is

Every workspace is a folder under Application Data\9xHarness\Workspaces\<name>. Conversations you have in that workspace are saved there as CONV-yyyymmdd-hhmmss.NBC, next to any text files you put there. Switching workspace switches the conversation history and the file list.

Everyday operations

  • Workspace - New Workspace creates a folder and selects it.
  • Workspace - New Text File in Workspace creates a file and opens it.
  • Workspace - Add File to Workspace copies a file into the current folder.
  • Workspace - Open Workspace Folder opens the folder in Explorer.
  • F5 or Workspace - Refresh re-reads the folder from disk.
  • Right-click a file in the tree for Open / Delete / Refresh.

Conversation files

Conversations are plain text with a short ; header. They can be opened in Notepad or the built-in editor, and they are what File - Save Conversation writes. Deleting a conversation file from the tree deletes it from disk.

Tip: keep one workspace per project. Everything the assistant produces for that project then lands in one folder you can copy to a floppy or a ZIP archive.
