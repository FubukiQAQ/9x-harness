9xHarness

老机器上的桌面智能助手。

9xHarness 是一个运行在老式个人电脑（Windows 95 / 98 / NT 4.0 / 2000 / XP）上的桌面助手。它把您的提问通过加密的安全连接发送到云端服务，再把回答 显示在这个三栏工作台里；它还可以读写您电脑上的文件、执行命令、查看系统信息—— 也就是所谓“工具调用”。

三个特点

  • 在老系统上也能安全上网。Windows XP 自带的加密组件只支持到 TLS 1.0， 早就不能用了。本程序内置完整的 SSL/TLS 1.2 组件（BearSSL），不依赖系统里的任何 加密服务，因此在 Windows 95 上一样能和现代服务器建立安全连接。
  • 明白自己住在旧机器里。程序发给云端的环境说明是专门写过的：它知道这台 电脑是 Windows XP、内存只有 128~512 MB、编码是 GBK、没有 PowerShell 也没有 Python。于是回答更贴合实际，不会让您去装那些根本装不上的现代软件。
  • 一个真正能干活的助手。列目录、读文件、写文件、在命令提示符里执行命令、 打开文件、把文字放进剪贴板。所有有风险的操作都会先弹出确认框。

开始之前

  1. 在「工具 - 设置」里填写服务器地址、型号名称与API 密钥， 然后按「测试连接」确认网络与加密通信正常；
  2. 在「工具 - 激活产品」里输入随光盘提供的产品序列号（CDK）。未激活时 可以使用 30 天 / 30 次会话的试用版。
提示：本软件本身不包含任何云端账号。如果您不清楚服务器 地址和密钥，请向提供本软件的单位或经销商索取。
